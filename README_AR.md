# سند 2.0

هذه نسخة مطورة من سند:
- واجهة جديدة بالكامل.
- ذكاء اصطناعي عبر OpenAI Responses API من خلال الخادم.
- البحث الحقيقي عن ورش/ميكانيكيين قريبين من GPS عبر OpenStreetMap Overpass.
- عدم فتح Google Maps تلقائيًا عند سؤال المستخدم عن ميكانيكي.
- تحديد موقع عالي الدقة من المتصفح.
- إدخال صوتي وقراءة الرد.
- أرقام الطوارئ الإماراتية.

## التشغيل
1. ثبّت Node.js.
2. افتح المجلد في Terminal.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاح OpenAI في `OPENAI_API_KEY`.
6. نفّذ: `npm start`
7. افتح `http://localhost:3000`

لا تضع مفتاح OpenAI داخل HTML؛ يجب أن يبقى على الخادم.
